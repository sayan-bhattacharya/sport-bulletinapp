# Score Adda

The daily sports adda for cricket and football — live state, sharp briefs, one habit.

**Live demo:** https://sayan-bhattacharya.github.io/sport-bulletinapp/

## Local

```bash
npm install
npm run dev
```

Remotion Studio (brand loop):

```bash
npm run remotion
```

Production build:

```bash
npm run build
npm run preview
```

## Stack

- Vite + React
- Remotion Player (looping hero film)
- Framer Motion (section reveals)
- GitHub Pages CI/CD (`dist/`)
